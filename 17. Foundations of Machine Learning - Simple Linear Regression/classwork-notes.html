Hour 1 — The Paradigm Shift

Every one of last session's tricks — sampling, averaging, guessing — was you, the human, doing the work. Machine Learning is what happens when you hand a computer a pile of data and let it find the pattern on its own. There are three ways it can go about that:

ParadigmHow it learnsEveryday example
SupervisedFrom labeled data — every example already comes with the correct answer attached, like a teacher checking homework.📧 Spam filter — trained on millions of emails already labeled "spam" / "not spam."
UnsupervisedFinds hidden patterns in unlabeled data — nobody tells it the groups beforehand; pure self-discovery.🎬 "You might like" — groups viewers with similar taste, no one labels the clusters.
ReinforcementLearning by trial and error through rewards and penalties — nobody labels the data, the machine just tries things and keeps what works.🐭 A mouse in a maze, or DeepMind's Atari Pong agent, trained purely on the score as a reward.

Real-estate platforms clustering listings into "Luxury Homes" or "Budget Homes" with zero labels given upfront is unsupervised learning in the wild — the algorithm finds the groups, humans just name them afterward.

Hour 2 — The Baseline Guess

Supervised learning splits into two flavors: predicting a category (Spam or Not?) or predicting a number (exact salary). Today is entirely the number version — Regression — and it starts from the simplest possible guess.

Setup: 42 employees at a tech company. We know each one's years of experience (X) and salary (Y). Challenge: predict Y using X.

First, forget X entirely. If a new employee joins and you must guess their salary right now, with zero other information, the best single number is the mean of all known salaries — the flat "Mean Line."

Residual = Actual (Y) − Predicted (Ŷ) The gap between a real value and our guess. Some employees sit above the mean line, some below it.

Obvious next idea: sum every residual to measure total error. It fails — positive and negative residuals cancel out, so the total can look deceptively close to zero even when individual guesses are way off. That failure is exactly why every error metric that follows squares the residual first.

Hour 3 — Simple Linear Regression

The flat Mean Line treats a fresh graduate and a 15-year veteran identically — but plot X back in, and the cloud of employees isn't a random blob, it tilts: more experience, more salary. That tilt is information the Mean Line was leaving on the table.

Y = β₀ + β₁X + ε β₀ (intercept) — where the line starts. β₁ (slope) — how steeply salary rises per year of experience. Notice the Mean Line was secretly this same formula with β₁ = 0 — a slope of nothing at all.
Mean Squared Error (MSE) — picture each residual as the side of a square; squaring it is literally the area of that square, so big misses create big squares fast.

How the machine actually finds β₀ and β₁: a game of hot and cold

  1. Propose a handful of nearby lines — nudge β₀ and β₁ by a small random amount, a few different ways.
  2. Score every candidate — compute the MSE for each nudged line. No guessing about quality, just measure it.
  3. Keep the warmest, discard the rest — lower MSE = warmer = keep it as the new "current line." Everything else is thrown away.
  4. Shrink the nudges, repeat — take smaller steps each round (cooling down) so it settles instead of overshooting forever.

This is Gradient Descent in plain English — the formal, calculus version is next session's entire topic. The line this process converges to is the OLS (Ordinary Least Squares) line: the mathematically-guaranteed minimum-MSE fit for the data.

Hour 4 — Evaluating the Model

A sloped line always looks fancier than a flat one — but "fancier" isn't the same as "better." Every point hides three distances, and squaring-and-summing each one across all 42 employees gives three named quantities:

DeviationDefinitionFeeds
TotalActual − Mean — how far this employee sits from doing nothing at allSST
ExplainedPredicted − Mean — what experience alone accounts forSSR
UnexplainedActual − Predicted — the leftover mistake the line still missesSSE
R² = SSR / SST = 1 − (SSE / SST) The proportion of the total variation that the model actually explains. Unitless and lands between 0 and 1 — you can compare a salary model's R² to a completely different weather model's. If SSE = 0, R² = 1 (perfect fit); if SSR = 0, R² = 0 (no better than the mean).

R² isn't the only score in town — RMSE and MAE are built from the same residuals, combined differently. RMSE squares every error before averaging, so one huge miss can drag the whole score up; MAE treats every error equally, in a straight line.

Two ways a model can lie to you

  • Underfitting — forcing a rigid straight line through data that naturally bends (e.g. experience vs. salary, which rises fast early on then plateaus later — diminishing returns). Watch for residuals that aren't random anymore: a systematic curve the line is blind to.
  • Overfitting — a jagged, chaotic curve that hits every single training point perfectly, but has memorized the noise, not the pattern. Complexity dial intuition: Train error keeps shrinking as complexity rises, while Test error eventually turns around and gets worse.

Where This Goes Next

Real predictions rarely rely on just one feature. The same OLS idea scales up effortlessly — just add more β's: Y = β₀ + β₁X₁ + β₂X₂ + β₃X₃ + … + ε. Same MSE, same OLS logic, just more dimensions. That's Multiple Linear Regression — the next stop, followed by the formal mechanics of Gradient Descent itself.
