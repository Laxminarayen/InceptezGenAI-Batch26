Hour 1 — The Cost Landscape

We're no longer asking "what's the salary?" — we're asking "which line is best?" That question lives in a completely different space: the cost function J takes the parameters (β₀, β₁) as input, not X.

Optimization — the general problem of finding the input that makes some function's output as small (or large) as possible. "Fitting a line" is secretly just optimization wearing a costume.

Plot every possible (β₀, β₁) pair as a point on a map — the cost landscape. Position = a line; color = how good that line is (darker = lower cost = better fit); the star marks the exact minimum OLS computes algebraically. For simple linear regression this landscape is always a smooth, single valley — a bowl, with exactly one lowest point no matter which direction you approach from.

Why a bowl and not a V? Squaring the error (the bowl) grows faster and faster the further you move from zero error; taking the absolute value (a V) grows at a constant rate. That difference in curvature is exactly why MSE — not MAE — is what gradient descent is built to walk down smoothly.

You have the luxury of a bird's-eye view of this map. A real algorithm starts at one random point and can only feel what's directly under its feet — the local slope. That's the whole problem Hour 2 solves.

Hour 2 — The Blindfolded Hiker

This is the entire idea behind Gradient Descent: you're on a foggy hillside, you can't see the valley floor, but you can feel which way is downhill by tilting your foot — one direction feels steeper-down than the other. Take a step that way. Repeat.

The algorithm, in five steps

  1. Start with a guess — any guess. Your first guess doesn't need to be good; you'll get to correct yourself repeatedly.
  2. Feel the slope. One number tells you which way is downhill and how steeply.
  3. Update: subtract the slope. new value = old value − (learning rate) × slope. Exactly like a thermostat: reading "+3" (too hot) turns the dial down; "−3" (too cold) turns it up.
  4. Repeat — go back to step 2 with the brand-new numbers.
  5. Stop when the slope is ~0. Flat ground in every direction means you're standing at the bottom.

Worked by hand: salary vs. age, 8 real people

Small enough to hand-compute, real enough to trust. Two passes:

  • One parameter first — forget age entirely, guess the same salary (β₀) for everyone. Gradient descent slides down a simple 1-D curve and lands exactly on the average.
  • Both parameters together — bring age back: predicted salary = β₀ + β₁ × age. Every round, compute both slopes and update both numbers simultaneously — the same update rule, just applied twice. It converges almost exactly to OLS's shortcut-formula answer.

The two parameters can't be solved one at a time — there's only one mistake per person, and both dials shape it together. Nudge either one and the same residuals change; it's a seesaw, not two independent problems.

Gradient — the direction of steepest increase at any point (and how steep it is). In 1D it's the familiar slope/derivative. In 2D (β₀ and β₁ together) it becomes an arrow pointing uphill — so gradient descent always steps in the opposite direction of the gradient. That minus sign is the whole trick.

The learning rate (α) scales every step. Too small and convergence crawls; the right size glides smoothly into the minimum, far faster than random "hot and cold" nudging ever could.

Hour 3 — Deriving the Gradient

The gradient arrow isn't magic — it's two ordinary formulas, one per parameter, built directly from the residuals you already know.

  • Nudge β₀ by a tiny amount h — every prediction shifts up by exactly h, so every residual shrinks by h. The resulting rate of change works out to −2 × (average residual).
  • Nudge β₁ by h instead — each prediction shifts by h × Xᵢ (bigger shift for bigger X), so the rate of change carries an extra Xᵢ: −2 × (average of residual × X).
Both slopes are built from residuals — that's not a coincidence. If the average residual is zero AND residuals no longer correlate with X, there's nothing left to improve — that's the minimum, and it's exactly where both gradient formulas hit zero.

The only calculus fact used anywhere in this derivation is the chain rule for a square: the derivative of (something)² is 2 × (something) × (derivative of that something). Everything else is bookkeeping — does this term contain β₀, or β₁, or not?

Hour 4 — Convergence & Pitfalls

Three practical stopping signals, usually combined:

  1. Gradient ≈ 0 — almost flat in every direction, basically at the bottom.
  2. Cost stops improving — if the last step barely moved J, further steps won't help much either.
  3. Max iterations — a safety net so training can't run forever.

If plain linear regression has an exact closed-form shortcut (OLS), why walk downhill at all? Because the shortcut only exists for a handful of models — Logistic Regression and neural networks have no such formula, and gradient descent is the general-purpose tool that works for all of them.

Two ways gradient descent breaks

  • Unscaled features — one raw feature in single digits and another in the thousands stretches the bowl into a narrow ravine, forcing tiny cautious steps in one direction while crawling in the other. Fix: scale features to similar ranges before training.
  • Divergence — push the learning rate too far and each "step downhill" overshoots so badly it lands higher than where it started. Cost doesn't shrink, it explodes.
Linear regression's cost landscape is always convex — a single smooth valley, which is exactly why it's the right place to learn gradient descent: you can always verify the answer against OLS's exact shortcut. Later, on messier landscapes (neural networks!), the bowl turns bumpy — many dips, and gradient descent can get stuck in a shallow one instead of the deepest one — and you'll trust the same walking algorithm without that safety net.

The Takeaway

Fitting a line is secretly an optimization problem over a bowl-shaped landscape. Gradient descent walks downhill using only the local slope — a slope that turns out to be two simple formulas built from residuals you already understood. Same update rule, whether it's 2 parameters or 2 million: compute the slope, subtract it, repeat. Every neural network you'll ever meet is just this, running millions of times.
