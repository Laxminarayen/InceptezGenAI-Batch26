Polynomial Regression

Linear Regression's exact machinery, handed engineered powers of X as extra columns — enough to draw curves without inventing a single new algorithm. Plus: the formal reason that same machinery breaks the moment the target becomes a 0/1 category instead of a number.

1.Polynomial Features

Y = β₀ + β₁X + β₂X² + β₃X³ + … + βₐXᵈ + ε Each power of X is computed, not measured, and treated as its own ordinary feature column. Degree d=1 recovers plain Linear Regression exactly.

Normalize every power before fitting — at X=15, X³=3,375 while X=15, a scale mismatch severe enough to make unscaled gradient descent lurch on one axis and crawl on another (see the Gradient Descent reference, Section 6).

2.Still Linear — In the Parameters

"Linear" in Linear Regression refers to linearity in the parameters β, not in X. Y = β₀+β₁X+β₂X² is non-linear in X (it curves) but perfectly linear in β — every term is a coefficient times a (possibly transformed) feature, summed. That's why OLS and Gradient Descent apply completely unchanged: to the optimizer, X² is indistinguishable from any other column.

3.The Bias-Variance Decomposition

Expected Test Error = Bias² + Variance + Irreducible Error Bias — error from a model too simple to capture the true pattern (underfitting). Variance — error from a model so flexible it fits noise specific to the training sample (overfitting). Irreducible error — noise no model can ever remove.

Increasing polynomial degree trades bias for variance: a low degree can't bend to match the true curve (high bias, low variance — the fit barely changes if you resample the training data); a high degree matches the training sample almost perfectly but swings wildly between different training samples (low bias, high variance). Total expected error is minimized somewhere in between — never at either extreme.

4.Choosing the Degree

Never choose degree by training error alone — it's monotonically non-increasing as degree grows (more columns can always fit training data at least as well, up to numerical limits). The honest procedure:

  1. Split into train/test (or use k-fold cross-validation for a more stable estimate on small datasets).
  2. Fit each candidate degree on training data only.
  3. Score every degree on held-out data; plot test error vs. degree.
  4. Pick the degree at the minimum of that curve — not the minimum of the training curve.

5.Regularization, Previewed: Ridge & Lasso

Instead of a hard degree cutoff, keep many polynomial terms but penalize large coefficients directly in the cost function — letting the optimizer decide how much each term is really worth.

Cost function addsEffect
Ridge (L2)λΣβₖ²Shrinks all coefficients toward zero, smoothly — none typically reach exactly zero.
Lasso (L1)λΣ|βₖ|Can shrink some coefficients to exactly zero — effectively performs feature selection.

λ (lambda) controls the penalty strength — λ=0 recovers plain OLS; large λ shrinks the model toward the trivial "predict the mean" baseline. Not this course's topic in depth, but this is precisely the tool built to solve Section 3's tradeoff without hand-picking a strict degree.

6.Why a Straight Line Fails for 0/1 Targets

Treat "approved" as 1 and "rejected" as 0, fit OLS the usual way, and two problems appear that no amount of more data fixes:

  • Unbounded output — a line has no ceiling or floor; step slightly outside the training data's range and it happily predicts things like 1.24 or −0.22 — not a valid probability under any interpretation.
  • Sensitivity to outliers in a new way — one honest, unusual data point (e.g. a well-qualified applicant who was still rejected) can pull the entire line, and therefore every other prediction, off course — because OLS is fitting a continuous quantity, an extreme y=0 or y=1 case is treated as being just as "extreme" as an extreme numeric outlier would be.

7.What a Valid Probability Function Needs

Two hard requirements, and exactly one standard function satisfies both at once (formalized in the Logistic Regression reference):

  • Always between 0 and 1 — a legitimate probability, for any input, with no exceptions.
  • Bounded reaction to outliers — one extreme point shouldn't be able to swing predictions for every other point.

The sigmoid function, σ(z) = 1/(1+e⁻ᶻ), is an S-shaped curve that satisfies both — it's next session's entire topic.

8.API Reference

ToolWhat it does
PolynomialFeatures(degree=d)Generates all polynomial (and, for multiple features, interaction) terms up to degree d.
Pipeline([...])Chains feature generation, scaling, and the regressor into one fittable object — avoids leaking test data into the scaler (see the KNN reference, Section on evaluation).
Ridge(alpha=λ) / Lasso(alpha=λ)Regularized linear models — alpha is scikit-learn's name for λ.

9.Worked Example

from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import cross_val_score

best_degree, best_score = None, -float("inf")
for degree in range(1, 8):
    model = make_pipeline(
        PolynomialFeatures(degree=degree),
        StandardScaler(),
        LinearRegression(),
    )
    scores = cross_val_score(model, X_train, y_train, cv=5, scoring="r2")
    if scores.mean() > best_score:
        best_degree, best_score = degree, scores.mean()

print(f"Best degree: {best_degree} (CV R² = {best_score:.3f})")

10.Summary

The whole idea, in one paragraph

Polynomial Regression is Linear Regression with extra, engineered feature columns — no new optimizer, no new cost function, just more terms for the exact same machinery. The bias-variance tradeoff means more terms aren't automatically better; the honest way to pick a degree is a held-out test score, not the training score, and Ridge/Lasso regularization offer a smoother alternative to a hard degree cutoff. That same machinery has a hard boundary, though: the moment the target is a category instead of a number, an unbounded straight line stops making sense, which is exactly the gap Logistic Regression's sigmoid is built to close.
