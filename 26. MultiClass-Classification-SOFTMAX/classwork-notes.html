Revision — Supervised Learning, One More Time

Supervised learning: X's (columns) and Y (target) — we're always trying to predict Y.

  • Regression: if the target is continuous, floating-point values (e.g. 0.005 ... 0.08 ... ∞).
  • Classification: if the target is discrete values (e.g. 0, 1, 2, 3, ...).
InputOutput
Linear RegressionX valuesContinuous number
Logistic RegressionX valuesSigmoid probability (0–1)
Polynomial Regressionx², x³ ... xⁿContinuous number (Y)
Polynomial Logisticx², x³ ... xⁿSigmoid probability (0–1)

All four of these are parametric models: they learn a fixed set of dials/knobs/regulators — β₀, β₁ ... βₙ — from the training data. The pipeline is always Data → Pre-process/EDA (missing values, outliers, inconsistent text, encoding, feature engineering, scaling, feature selection) → Model Train → Learned Parameters → Predict.

KNN — no dials at all

KNN makes no assumption about the relationship between X and Y, and has no learnable knobs. For a new point Z, measure its distance (Euclidean, Manhattan, Cosine, or Minkowski) to every X in the training data, and let the K nearest values decide the answer:

  • Regression: K-averaged output → a continuous number.
  • Classification: K-mode output → a discrete decision.

Problem: KNN is a lazy learner — every row stays in memory, and every prediction re-does the distance calculation on the fly. Nothing is learned ahead of time.

One-vs-Rest (OvR) — The First Instinct For Multiclass

Output is no longer binary — it's Low / Medium / High risk. One-vs-Rest trains one model per class, each one isolating a single class against everything else:

ModelPredictsvs.
Model ALow Risk{Medium, High}
Model BMedium Risk{Low, High}
Model CHigh Risk{Low, Medium}

In general: K classes → K models (or K output nodes). Each model tries to isolate one specific class from the rest, which makes each model individually interpretable — but the K scores are produced independently, so nothing forces them to agree or to add up to 1.

Binary vs. Multiclass vs. Multi-label

Worth separating three different problems clearly:

  • Binary: exactly 2 outcomes (e.g. Cat vs. Not-Cat).
  • Multiclass: exactly one correct label out of K options (e.g. a photo is a Cat, a Dog, or a Bird — never more than one).
  • Multi-label: more than one label can apply, or the answer itself can be uncertain (e.g. Yes / No / Maybe). A different problem from today's.

Entropy, Generalized to K Classes

Decision Trees already had the right formula — it just happens to work for any number of classes: H(S) = − Σ p(xᵢ) · log₂ p(xᵢ). Two worked examples from 12 samples:

Classes (K)SplitH(S)
3 (Low/Med/High)4/12 each → p = 1/3 each1.585
43/12 each → p = 1/4 each2.0
Maximum possible impurity, K classes, evenly split: Hmax = log₂(K) — e.g. log₂(3) = 1.585, log₂(4) = 2.0

Whenever a decision tree node has K classes, that node can never be more confused than log₂(K) bits — a perfectly even split across all K classes.

Softmax Regression — Rebuilding Logistic Regression For K Classes

Logistic regression's one line, one sigmoid output isn't enough for multiclass — so linear regression itself gets reworked. With K classes, fit K regression lines, one per class:

yk = Wkx + b  (equivalently, zk = β₀,ₖ + β₁,ₖ·x)

Step 1 — one-hot encode the target, one column per class (a "1" marks which class that row is, a "1 Hot Vector"):

ClassOne-Hot [Low, Med, High]
Class 0 — Low Risk[1, 0, 0]
Class 1 — Medium Risk[0, 1, 0]
Class 2 — High Risk[0, 0, 1]

By hand, once — an applicant at x = 3.31

Classβ₀β₁z = β₀ + β₁·x
Low4.50−1.200.528
Medium0.800.251.628
High−3.201.100.441

Three raw scores — not probabilities yet. To turn them into a proper probability distribution (all positive, all summing to 1), use Softmax:

p̂k = ezk / (ez₀ + ez₁ + ez₂) Convert continuous values into a probability where the total across all classes adds up to 1.
e0.528 + e1.628 + e0.441=1.696 + 5.093 + 1.554 = 8.343
Low1.696 / 8.343= 0.20
Medium5.093 / 8.343= 0.61
High1.554 / 8.343= 0.18

Final output vector: [0.20, 0.61, 0.18] — the largest entry (argmax) wins, so this applicant is classified Medium Risk.

Confusion Matrix, Multiclass — Where We Left Off

A 2×2 confusion matrix (TP/TN/FP/FN) grows into a K×K grid — every actual class can be predicted as any of the K classes, and the diagonal is "got it right."
