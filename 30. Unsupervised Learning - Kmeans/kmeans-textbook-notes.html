K-Means Clustering

The default algorithm for partitioning unlabeled data into K groups: pick K centroids, assign every point to its nearest one, move each centroid to the mean of its assigned points, and repeat until nothing changes. Simple, fast, and the right first tool to reach for whenever there's no target column to learn from.

1.Supervised vs. Unsupervised Learning

Every algorithm up to this point — Linear/Logistic Regression, KNN, Decision Trees, Random Forest, AdaBoost — is supervised: training data includes both features (X) and a target (y), and the model's entire job is to learn a mapping from one to the other, checked against the true y.

Unsupervised learning removes y entirely. There is no "correct answer" in the training data — only X. The task becomes: find useful structure in the data on its own. Clustering is the most common unsupervised task: partition the rows into groups such that rows in the same group are more similar to each other than to rows in other groups.

There is no accuracy score in clustering, because there is nothing to be "correct" against. Every evaluation method in this chapter (inertia, silhouette score) measures internal consistency of the groups found — not agreement with ground truth, because none exists.

2.The Algorithm, Formally

Given n points and a chosen K, K-Means (Lloyd's algorithm) proceeds:

  1. Initialize K centroids, μ₁ … μ_K (randomly, or via k-means++, Section 6).
  2. Assignment step: for every point xᵢ, assign it to the cluster whose centroid is closest: c(xᵢ) = argmin_k ‖xᵢ − μ_k‖².
  3. Update step: recompute each centroid as the mean of the points currently assigned to it: μ_k = (1/|S_k|) Σ_{x∈S_k} x.
  4. Repeat steps 2–3 until no point changes cluster (convergence), or max_iter is reached.
Objective (Inertia / WCSS): J = Σₖ Σ_{x∈S_k} ‖x − μ_k‖² K-Means minimizes the total within-cluster sum of squared distances. Each step of the algorithm (assignment, then update) never increases J — which is exactly why it's guaranteed to converge, though not necessarily to the global minimum (Section 6).

3.Distance Metrics

K-Means almost always uses Euclidean distance: for 2D points, d = √((x₂−x₁)² + (y₂−y₁)²), generalizing to any number of dimensions by summing squared differences across every feature.

Euclidean distance implicitly assumes clusters are spherical (round) in the feature space — it penalizes distance equally in every direction. This single assumption is the root cause of most of K-Means' limitations (Section 8).

4.Choosing K: The Elbow Method & Silhouette Score

K is a hyperparameter the analyst must choose — there's no way to "fit" it from the data the way a model fits its weights. Two common techniques:

Elbow Method

Fit K-Means for a range of K values and plot inertia (J) against K. Inertia always decreases as K increases (more clusters can only reduce total distance), but the rate of decrease slows sharply past the "true" number of clusters — the elbow. On the Mall Customer dataset (200 rows, Age/Income/Spending Score):

The drop from K=4→5 (≈28%) is noticeably larger than K=6→7 (≈12%) or later steps — consistent with K=5 being a reasonable elbow for this dataset.

Silhouette Score

s(i) = (b(i) − a(i)) / max(a(i), b(i)) a(i) = average distance from point i to other points in its own cluster (cohesion). b(i) = average distance from i to points in the nearest other cluster (separation). s(i) ranges from −1 (likely misassigned) to +1 (well-clustered); the mean silhouette score across all points is often used alongside the elbow method to cross-check a choice of K.

5.Feature Scaling Matters

Because the algorithm is driven entirely by Euclidean distance, a feature with a numerically larger range dominates the distance calculation regardless of its actual importance. Annual Income ($15k–$140k) would swamp Spending Score (1–100) if left unscaled. Standardizing features (zero mean, unit variance) before clustering is standard practice — exactly the same StandardScaler pattern used for KNN (Class 23) and Logistic Regression (Class 22).

6.Initialization & Local Optima

K-Means is only guaranteed to converge, not to find the global best split — a poor random choice of starting centroids can lock the algorithm into a worse local optimum. Two mitigations, both standard in scikit-learn:

  • k-means++ initialization (the default) — spreads initial centroids apart deliberately instead of placing them fully at random, which empirically converges faster and to better solutions.
  • n_init — re-run the entire algorithm this many times with different random seeds and keep whichever run achieved the lowest inertia.

8.Limitations

  • Assumes round, similarly-sized clusters. Elongated, nested, or very differently-sized natural groups are frequently split incorrectly.
  • Sensitive to outliers. A centroid's position is the mean of its members — a single extreme point can pull it noticeably off-center.
  • Requires choosing K in advance, with no ground truth to validate the choice against.
  • Only works cleanly on numeric features — categorical columns need to be re-encoded or a different algorithm (Hierarchical Clustering, Section 7) entirely.

10.Worked Example

import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

features = ['Age', 'Annual Income (k$)', 'Spending Score (1-100)']
X = df[features].to_numpy()

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

kmeans = KMeans(n_clusters=5, init='k-means++', n_init=10, random_state=42)
df['cluster'] = kmeans.fit_predict(X_scaled)

print("Inertia:", kmeans.inertia_)
print("Centroids (scaled space):", kmeans.cluster_centers_)

# Interpret each cluster after fitting — K-Means never names groups itself:
summary = df.groupby('cluster')[features].mean().round(1)
print(summary)
The classwork notebook fits on unscaled features for simplicity (Age, Income, and Spending Score happen to be on roughly comparable scales for this dataset) — but scaling first, as above, is the correct default whenever feature ranges differ meaningfully.

11.Summary

The whole idea, in one paragraph

K-Means partitions unlabeled data into K groups by alternating two simple steps: assign every point to its nearest centroid, then move each centroid to the mean of its current members — repeating until nothing changes. It minimizes total within-cluster squared distance (inertia), is sensitive to feature scale and initialization (mitigated with scaling and k-means++/n_init), and assumes roughly round, similarly-sized clusters. Choosing K itself has no ground truth to check against — the elbow method and silhouette score are the standard heuristics, not guarantees.
