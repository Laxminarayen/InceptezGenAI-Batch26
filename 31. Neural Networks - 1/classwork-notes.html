The Big Picture: Traditional ML → Deep Learning → ChatGPT

A model is a mathematical mapping from X (input) to y (output) — it tries to remember / memorise patterns in new data, and learn useful representations. The field progresses in three stages:

ApproachHow it worksExample
Rule-Based SystemsA human writes predefined rules (if/else) that produce the outputIf colour red & shape roundish → Apple, else → Banana
Machine LearningGive it examples; it learns the patterns → a learned modelSpam detection from labelled emails
Deep LearningThe model learns useful features itself, through trained layersLanguage, images, speech

Three foundations under all of this: (1) Python — the tool/language we code these algorithms with; (2) Statistics & Probability — the mathematical foundation; (3) Artificial Intelligence — the umbrella.

Why Rules Don't Scale: The Rule Explosion Problem

Consider spam detection with hand-written rules: flag "FREE", flag "Congrats! You've won a free iPhone", flag "AIRTEL". But "Inceptez — join free session tomorrow" is NOT spam. How many rules should you write — 10? 100? 10,000?

Rule Explosion Problem: the possibility of patterns becomes hard to describe, and the number of rules grows without bound. The ML fix: stop writing rules, show the system examples, and let it learn the patterns into a learned model.

Why Do We Need Deep Learning?

Traditional ML can learn non-linear patterns — via Polynomial features, Decision Trees, Random Forests, and SVM kernels. The problem is the feature explosion when you force non-linearity in by hand:

Degree-2 polynomial features on 1000 inputs = 1 + 1000 + 1000 + C(1000, 2) = 501,501 features Bias (1) + linear terms (1000) + squared terms (1000) + cross-terms C(1000,2)=499,500. The hand-crafted feature space blows up to half a million columns. (For 100 inputs it's already 5,151.)

Deep Learning's answer: introduce and learn useful non-linear representations through trained layers, rather than manually specifying every pattern of features.

When I have Random Forest (which also does feature importance), why Deep Learning?

  • RF shines on structured data — rows and columns in tables. Often the right first choice there.
  • When data has bigger complexity — language, images, speech, millions of pixels/words — RF struggles: RF with millions of raw features is slow, and because each tree doesn't look at previous trees, genuinely complex patterns can be hard to capture.

The Neuron: The Smallest Unit

A neural network is built from neurons. A neuron takes input features, computes one weighted sum plus a bias, and passes on the result:

z = w₁x₁ + w₂x₂ + w₃x₃ + b Weights (w₁, w₂, w₃) = how much each input matters (multiplicative learnable parameters). Inputs (x₁, x₂, x₃) = feature columns. Bias (b) = an adjustable threshold / shift (additive learnable parameter).

A Friendly Neuron: Predicting Salary

Model: Salary = 20,000 + 5,000 × experience. A fresher (experience = 0) earns the base ₹20,000 — that's the bias b. Each year adds ₹5,000 — that's the weight w. For 0–3 years, the straight line fits perfectly:

The one disadvantage: this system is linear. z = w₁x₁ + w₂x₂ + b is just the equation of a straight line (w₁, w₂ are slopes). It can never bend to catch the jump at 4+ years.

Aside — is Polynomial Regression linear? It breaks linearity w.r.t. the input, but stays linear w.r.t. the learned parameters: y = w₁x + w₂x² is linear in w₁, w₂ (treat x² as just another feature z₂). So it is still a linear model. A neural network is a genuinely non-linear model.

The Missing Ingredient: Activation Functions

To bend the line, a neuron applies a non-linear activation function f to its weighted sum: ŷ = f(z). This is the single thing that introduces non-linearity into a neural network.

ReLU (Rectified Linear Unit): a = ReLU(z) = max(0, z) The most common activation. Negative inputs → 0; positive inputs pass through unchanged.

Affine, Then Non-Linear: The Vocabulary

Old notationNeuron notationRole
y = mx + c (affine)z = Wx + bThe linear / affine part

c (intercept)b (bias)Additive learnable parameter

A single neuron = an affine transform (Wx + b) followed by a non-linear activation f. Stack many of these and you get a neural network.

From Neuron to Network: The Hidden Layer

A hidden layer is a collection of neurons. The same salary curve, built as a 2-neuron hidden layer feeding one output neuron, at experience = 5:

UnitComputationOutput
Hidden neuron h₁ReLU(5·5 + 20)45
Hidden neuron h₂ReLU(1·5 − 3)2
Output neuron S1·h₁ + 10·h₂ + 0 = 45 + 20₹65k ✓

Same ₹65k answer — now produced by a mini-network. Global behaviour emerges from additive & multiplicative mixing of input features across neurons.

How are the weights set? In this example they were handed to us. In a real network, all weights and biases are learnt via optimization — the algorithm is backpropagation (next session). Architecture: Input layer (features) → Hidden layer(s) (neurons, each affine + activation) → Output layer (ŷ).

The Seven Terms

  1. Neuron — smallest unit; one weighted sum + bias.
  2. Weights — multiplicative learnable parameters.
  3. Bias — additive learnable parameter / threshold shift.
  4. Activation Function — the non-linearity added after each hidden layer (e.g. ReLU).
  5. Affine — the Wx + b part (= mx + c).
  6. Neural Network — many neurons wired across layers.
  7. Hidden Layer — a collection of neurons between input and output.

Interview Questions

  1. What is the difference between ML & DL? Are DL systems always better? No. DL wins on raw complexity (images, language, speech). On structured tabular data, traditional ML (e.g. Random Forest) is often better, faster, and more interpretable.
  2. Is Polynomial Regression linear? Yes — non-linear w.r.t. the input, but linear w.r.t. the learned parameters, so it's still a linear model. (Difference between Polynomial and a Neural Network: the NN is a genuinely non-linear model.)
  3. What introduces non-linearity in a neural network? The activation function — the non-linearity added after each hidden layer.
