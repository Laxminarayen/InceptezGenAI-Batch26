Three Ways to Build an "Intelligent" System

Rule-based → Machine Learning → Deep Learning

📜

Rule-Based Systems

A human writes the rules: if colour is red and shape is roundish → Apple, else → Banana. Predefined rules produce the output. Works — until the patterns get hard to describe.

🤖

Machine Learning

Instead of rules, give it examples and let it learn the patterns. Human-engineered features → a learned model (classification / regression).

🧠

Deep Learning

The model learns useful features itself, through trained layers, instead of a human specifying every pattern.

Why Rules Don't Scale · The Spam Example

The Rule Explosion problem

To catch spam with hand-written rules: flag "FREE", flag "Congrats! You won a free iPhone", flag "AIRTEL"… but "Inceptez — join free session tomorrow" is not spam. How many rules should you write — 10? 100? 10,000?

🚩 Rule Explosion: the number of rules needed grows without bound, and they start contradicting each other.
The ML fix
Don't write rules. Show the system labelled examples of spam / not-spam and let it learn the patterns — a learned model, not a predefined rulebook.
But Traditional ML Can Already Do Non-Linearity…

So why do we need Deep Learning?

Yes — ML models can learn non-linear patterns, via Polynomial features, Decision Trees, Random Forests, SVM kernels. The problem is what happens to the feature count when you force non-linearity in by hand.

📐 Degree-2 polynomial features on 1000 inputs = 1 + 1000 + 1000 + C(1000,2) = 501,501 features. The hand-crafted feature space explodes.
Deep Learning's answer
Introduce & learn useful non-linear representations through trained layers, rather than manually specifying every pattern of features.
When I Have Random Forest (Which Also Finds Features)… Why DL?

Structured tables → RF. Images, language, speech → Deep Learning.

🗂️

Random Forest shines on structured data

When features are structured — rows and columns in a table — RF is excellent and often the right first choice.

🖼️

DL shines on raw complexity

When the data has bigger complexity — language, images, speech, millions of pixels or words — RF struggles. DL learns the representation itself.

RF with millions of raw features → prohibitively slow, and because each tree doesn't look at previous trees, genuinely complex patterns can be hard to capture. Deep Learning was built for exactly this regime.
The Smallest Unit

A neural network is built from neurons

Neuron
The smallest unit of a neural network. It takes input features, computes one weighted sum plus a bias, and passes the result on. That's it — everything else is many of these, wired together.
z = w₁x₁ + w₂x₂ + w₃x₃ + b  — a weighted sum of inputs, plus an adjustable bias.
Anatomy of the Weighted Sum

Weights, inputs, and a bias

z = w₁x₁ + w₂x₂ + w₃x₃ + b

⚖️

Weights (w₁, w₂, w₃)

How much each input feature matters — the multiplicative learnable parameters. These are learned from data.

📊

Inputs (x₁, x₂, x₃)

The input feature columns — e.g. years of experience, for a salary model.

➕

Bias (b)

An adjustable threshold / shift — the additive learnable parameter. Lets the neuron fire even when all inputs are zero.

A Friendly Neuron · Predicting Salary

Salary = 20,000 + 5,000 × experience

A fresher (experience = 0) earns the base ₹20,000 — that's the bias, b. Each extra year adds ₹5,000 — that's the weight, w. For 0–3 years, this straight line fits the real salaries perfectly.

The One Disadvantage

This neuron is linear

z = w₁x₁ + w₂x₂ + b is just the equation of a straight line (or plane) — w₁, w₂ are slopes. It can never bend to fit the jump at 4+ years. (Polynomial Regression breaks linearity w.r.t. the input, but stays linear w.r.t. the learned parameters — so y = w₁x + w₂x² is still a linear model.) To bend, a neuron needs one more ingredient.

The Missing Ingredient

The Activation Function

Activation Function
A non-linear function f applied to the neuron's weighted sum z. ŷ = f(z). This is the single thing that introduces non-linearity into a neural network — the key idea that separates it from a plain linear model.
ReLU — Rectified Linear Unit
The most common activation: ReLU(z) = max(0, z). Negative inputs become 0; positive inputs pass through unchanged. Dead simple, and enough to bend the line.

How Do the Weights Get Set?

Learned via backpropagation

In our salary example the weights and biases were handed to us. In a real network, all of the weights and biases are learnt via optimization — the algorithm is called backpropagation. (The full mechanics are the next session.)

The architecture, named
Input layer (features) → one or more Hidden layers (collections of neurons, each affine + activation) → Output layer (the prediction, ŷ).

Interview Questions

Three you'll be asked

❓

ML vs DL — is DL always better?

No. DL wins on raw complexity (images, language, speech). On structured tabular data, traditional ML (e.g. Random Forest) is often better, faster, and more interpretable.

❓

Is Polynomial Regression linear?

Yes — it's non-linear w.r.t. the input, but linear w.r.t. the learned parameters, so it's still a linear model. A neural network is a genuinely non-linear model.

❓

What introduces non-linearity in a NN?

The activation function — the non-linearity added after each hidden layer. Without it, stacked layers collapse back into one linear transform.
