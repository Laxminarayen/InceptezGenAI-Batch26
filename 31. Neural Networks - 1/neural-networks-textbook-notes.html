1.Rule-Based → ML → Deep Learning

Three generations of "intelligent" systems, each removing a layer of human effort:

ApproachWho defines the logicBreaks down when…
Rule-BasedA human hand-writes if/else rules.Patterns become too numerous or subtle to enumerate — the Rule Explosion problem (spam detection needs thousands of brittle, conflicting rules).
Machine LearningHuman designs the features; the model learns the mapping from labelled examples.The right features are themselves hard to design — e.g. raw pixels, audio, text.
Deep LearningThe model learns both the features (representations) and the mapping, through trained layers.Data is small and already well-structured — classical ML is often better there (Section 10).

2.The Feature-Explosion Argument

Traditional ML can model non-linearity — through polynomial features, tree splits, or kernels. The cost is a combinatorial blow-up in the number of hand-constructed features. For a degree-2 polynomial expansion of d inputs:

#features = 1 (bias) + d (linear) + d (squares) + C(d, 2) (pairwise cross-terms) d = 100 → 1 + 100 + 100 + 4,950 = 5,151.   d = 1,000 → 1 + 1,000 + 1,000 + 499,500 = 501,501.

The number of pairwise interactions grows as roughly d²/2. For images (millions of pixels) or text (large vocabularies), this is hopeless. Deep learning sidesteps it by learning which non-linear combinations matter, through trainable layers, instead of pre-materialising all of them.

3.The Neuron, Formally

A neuron is the smallest computational unit of a network. Given inputs x₁…x_n, it computes a weighted sum (an affine transform) and then applies an activation:

z = Σᵢ wᵢxᵢ + b = w₁x₁ + w₂x₂ + … + w_nx_n + b  ;  a = f(z) wᵢ = weights (multiplicative learnable parameters), b = bias (additive learnable parameter), f = activation function. The pre-activation z is often called the "logit" or "weighted sum"; a is the neuron's output / activation.

The weights say how much each input matters; the bias shifts the threshold at which the neuron becomes active, letting it respond even when every input is zero.

4.Why a Linear Neuron Isn't Enough

Without an activation (or with a linear one), a neuron computes z = Wx + b — the equation of a line / plane, with the weights as slopes. The deeper problem: a stack of purely linear layers collapses into a single linear layer. If layer 2 computes W₂(W₁x + b₁) + b₂, that equals (W₂W₁)x + (W₂b₁ + b₂) — still just one affine map. No matter how many linear layers you stack, you can only ever represent a straight line.

On Polynomial Regression: y = w₁x + w₂x² breaks linearity with respect to the input x, but is still linear with respect to the learned parameters w₁, w₂ (treat x² as a second feature). So it remains a linear model, fit by the same least-squares machinery. A neural network, by contrast, is non-linear in its parameters — which is exactly what the activation function buys.

5.Activation Functions

The activation function f is the sole source of non-linearity in a neural network. It is applied after each hidden layer's affine transform.

ActivationFormulaNotes
ReLUmax(0, z)The default for hidden layers. Cheap, sparse, avoids vanishing gradients for z > 0. Can "die" if stuck at z < 0.
Sigmoid1 / (1 + e⁻ᶻ)Squashes to (0, 1). Used for binary output probabilities; saturates and vanishes gradients in deep hidden stacks.
Tanh(eᶻ − e⁻ᶻ)/(eᶻ + e⁻ᶻ)Squashes to (−1, 1); zero-centred, often preferred over sigmoid for hidden layers historically.
Softmaxe^{zⱼ} / Σₖ e^{zₖ}Multiclass output layer — turns a vector of logits into a probability distribution (same function met in Logistic Regression, Class 26).

ReLU — Rectified Linear Unit — is the workhorse: negative pre-activations are clamped to 0, positive ones pass through unchanged. That single bend is enough to build arbitrarily complex piecewise-linear functions when many are combined.

6.The Salary Neuron, Worked

Base model (linear neuron): Salary = 20,000 + 5,000·x, where x = years of experience. Bias b = 20,000 (a fresher's salary), weight w = 5,000 (per-year raise). It fits perfectly for x ≤ 3, but real salaries jump faster afterward. One ReLU term fixes it:

Salary = 20,000 + 5,000·x + 10,000·ReLU(x − 3) The ReLU term contributes 0 while x ≤ 3, then adds 10,000·(x−3), bending the curve upward exactly where the data does.
x (experience)Linear only+ ReLU termActual
0₹20k₹20k₹20k
3₹35k₹35k₹35k
4₹40k₹50k₹50k
5₹45k₹65k₹65k

Vocabulary alignment: the affine part z = Wx + b is the same object as the familiar y = mx + c, with W ↔ m (multiplicative/slope) and b ↔ c (additive/intercept). The activation f(z) is the new, non-linear piece.

7.From Neuron to Network

A hidden layer is a collection of neurons that all read the same inputs in parallel; their outputs become the inputs to the next layer. The salary curve above can be reproduced by a 2-neuron hidden layer feeding a single output neuron:

h1 = ReLU(5*x + 20)     # hidden neuron 1
h2 = ReLU(1*x - 3)      # hidden neuron 2
S  = 1*h1 + 10*h2 + 0   # output neuron (linear combination)

# at x = 5:
# h1 = ReLU(45) = 45,  h2 = ReLU(2) = 2
# S  = 1*45 + 10*2 = 65   -> ₹65k   (matches the actual)

The architecture is: Input layer (raw features) → one or more Hidden layers (each neuron = affine + activation) → Output layer (the prediction ŷ). Global behaviour emerges from the additive and multiplicative mixing of input features across many neurons.

8.Universal Approximation

The reason this matters: the Universal Approximation Theorem states that a feed-forward network with a single hidden layer containing enough neurons, and a non-linear activation, can approximate any continuous function on a bounded domain to arbitrary accuracy. Intuitively, each ReLU neuron contributes one "bend," and summing enough bends traces out any shape. The activation is non-negotiable — remove it and the whole network reduces to a single line (Section 4), approximating only linear functions.

9.How Weights Are Learned (Preview)

In the salary example the weights and biases were given. In practice they are learned by optimization: define a loss (e.g. squared error for regression, cross-entropy for classification), then adjust every weight and bias to reduce it. The algorithm that computes how to adjust each parameter is backpropagation — the chain rule applied layer by layer, feeding gradient descent (Class 18). That mechanism is the subject of the next session; the key idea here is only that the parameters are fit from data, not hand-set.

10.ML vs. Deep Learning: When to Use Which

Traditional ML (e.g. Random Forest)Deep Learning
Best data typeStructured / tabular (rows & columns)Unstructured: images, language, speech, high-dimensional raw signals
Feature engineeringHuman-designed featuresLearned representations
Data neededWorks with modest datasetsTypically needs large datasets
InterpretabilityHigher (feature importance, tree paths)Lower (a "black box," though tooling exists)
Compute costLowerHigher (often GPUs)
"Is deep learning always better?" — No. On structured tabular problems, Random Forest / gradient-boosted trees frequently match or beat neural networks, train faster, and explain themselves more readily. Deep learning's advantage shows up precisely where feature design by hand is infeasible.

11.Summary

The whole idea, in one paragraph

Deep learning replaces hand-crafted features with representations learned through trained layers, which is the only tractable approach once inputs are high-dimensional and unstructured (the degree-2 feature count on 1,000 inputs is already 501,501). Its atom is the neuron: an affine transform z = Wx + b followed by a non-linear activation f. The activation is essential — without it, any stack of layers collapses to a single line. ReLU, max(0, z), is the standard choice; one ReLU term was enough to bend a linear salary model to fit real data, and a few neurons in a hidden layer reproduce the same curve. In real networks the weights and biases are learned by backpropagation and gradient descent — the next session's topic.
