Recap: The Salary Network

One input (experience x), a hidden layer of two neurons (each affine + ReLU), one output neuron that mixes them. The weights that were set by hand last time are what the network will now learn.

ŷ = v₁·h₁ + v₂·h₂ + c,   where   h₁ = ReLU(w₁x + b₁),   h₂ = ReLU(w₂x + b₂) Hyperparameters we choose: number of hidden neurons / layers, and the choice of non-linearity (ReLU). Everything else is learned.

Forward Pass: Make a Guess (x = 5)

With w₁=4, b₁=20, w₂=1, b₂=−3, v₁=1, v₂=10, c=0:

The network guesses ₹60k. The real salary for 5 years is ₹65k.

The Loss: How Wrong Were We?

L = ½(ŷ − y)² = ½(60 − 65)² = ½(−5)² = 12.5 Squaring makes the error positive and punishes big misses; the ½ cancels the 2 when differentiating. This is MSE for one row.
Loss vs. Metric. The model learns from the loss (differentiable, e.g. MSE / log-loss), not from a metric (Accuracy, F1). A metric is a human-readable score but is often not differentiable — its gradient is zero almost everywhere, so you can't descend it. "That which is not differentiable cannot go through."

Backpropagation: Two Directions of Information Flow

Forward prop: Input → Hidden → Output → Loss. Backward prop: Loss → output gradients → hidden-layer gradients → input-side gradients. Backpropagation measures the contribution of each parameter towards the loss.

What is a gradient?

∂L/∂w = "how does my loss change when I make a small change to a particular weight, holding the others fixed?" A positive gradient means increasing that weight increases loss (so decrease it); a negative gradient means increasing it decreases loss (so increase it). Gradients come from differentiation — which is exactly why the loss must be differentiable.

The chain rule for w₁

∂L/∂w₁ = ∂L/∂ŷ · ∂ŷ/∂h₁ · ∂h₁/∂z₁ · ∂z₁/∂w₁ = (−5)·(1)·(1)·(5) = −25 ∂L/∂ŷ = ŷ−y = −5 (how loss changes w.r.t. predicted salary). ∂ŷ/∂h₁ = v₁ = 1 (how output changes w.r.t. the hidden neuron). ∂h₁/∂z₁ = 1 (ReLU slope, since z₁=40>0). ∂z₁/∂w₁ = x = 5 (how the weighted sum changes w.r.t. w₁).

Epoch / Batch / Iteration

  • Epoch — one complete pass through the entire dataset (all rows seen once).
  • Batch — a chunk of rows processed together before one update. 1000 rows in batches of 100 → 10 batches.
  • Iteration — one optimizer step (one batch's worth). 10 batches → 10 iterations = 1 epoch.
Per-row (batch=1): sensitive optimizer, every row's pattern counts — SE = ½(ŷ−y)². Mini-batch: a little smoothed (e.g. 100 rows). Full-batch: one update per epoch over all N rows — MSE = (1/2N)Σ(ŷ−y)². Our tiny SalaryNet trains full-batch on all 11 rows at once.

SalaryNet in PyTorch

Why PyTorch (or TensorFlow)? They let us use GPUs efficiently and compute every gradient automatically — loss.backward() runs the entire chain rule for us.

class SalaryNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.hidden = nn.Linear(1, 2)   # 1 input -> 2 hidden (h1, h2)
        self.relu   = nn.ReLU()         # activation
        self.output = nn.Linear(2, 1)   # 2 hidden -> 1 output
    def forward(self, x):
        h = self.relu(self.hidden(x))   # weighted sum -> ReLU
        return self.output(h)

loss_fn   = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.02)

for epoch in range(3000):
    pred = model(X)              # 1. forward (guess)
    loss = loss_fn(pred, y)      # 2. measure error
    optimizer.zero_grad()        # 3. reset old gradients (factory reset)
    loss.backward()              # 4. backprop (how to improve)
    optimizer.step()             # 5. nudge the weights

torch.save(model.state_dict(), "salary_net.pth")   # save just the weights

By default PyTorch initialises weights randomly; in class we copied in sensible starting weights to trace the math. Adam is the optimizer (it decides each nudge); lr=0.02 is the learning rate. We save only the state_dict — the learned numbers — not the whole Python object, because that's the portable way to ship a model.

Package in Flask & Deploy to GCP

The trained model is loaded once at startup by a small Flask app (app.py) that serves a web form at /, a JSON API at /api/predict, and /health for the cloud to check it's alive — all on port 8080. Then we push to GitHub and deploy on a Google Cloud e2-small VM: create the VM, open port 8080 with a firewall rule and the salarynet tag (in Cloud Shell), then SSH in, install git + venv, clone, and run.
