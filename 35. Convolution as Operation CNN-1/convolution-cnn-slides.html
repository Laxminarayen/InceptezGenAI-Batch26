Today's question: plain neural networks worked for MNIST — so why do they not truly "understand" images? There is something more going on.
Part II · What Does a Neural Network Understand?

Flattening an image loses its structure

To feed a 28×28 image to a dense network we flatten it into 784 pixel values — row after row stacked into one long column. The network then takes a global weighted sum of all 784 at once.

28 × 28 image → flatten → 784 × 1 vectorRows are laid end-to-end. The network sees a list of numbers, not a picture.
🚩 Pixel 1 and pixel 6 may be right next to each other in the image, but after flattening they can land far apart in the vector — their spatial / local relationship is lost.
Spatial information
Where pixels are located and how neighbouring pixels relate to each other. A dense net has no local connectivity — it can't see that nearby pixels form a stroke.
Problem Definition

The structure is what defines a number

Pixels 1, 2, 6, 7 are close to each other — that arrangement is what makes a digit look like a "4" and not a "9". A global weighted sum can total the right brightness while completely missing the local pattern / alignment.

✓ We need a network that preserves spatial information — one that looks at small neighbourhoods and asks "is there an edge here?" before combining them.
Why did MNIST still work with a dense net? Because MNIST as an image is simple — centred, clean, low-res. Real images (cats, dogs, scenes) are not that forgiving.
Part IV · A Spatial-Information-Preserving Network

What makes up an image?

Lines, edges and contours. If we had functions that extract lines, edges and contours from an image — and made them learnable — the network could learn and extract exactly the useful information it needs for proper classification.

The idea
Focus on small functions that extract lines / edges / contours from the image. Make a neural network learn those functions by gradient descent.
That spatial-preserving, edge-extracting network is the Convolutional Neural Network (CNN). Its core operation is convolution.
Part V · The Convolution Operation

A small filter slides across the image

Convolution is an operation where a small filter (kernel) moves across an image and produces a response at every position. At each stop it does an element-wise multiply of the overlapping patch with the kernel, then sums — one number per position.

response = Σ (image patch × kernel)Slide the kernel one step at a time; the grid of responses is the feature map.
Kernel / Filter
A small matrix (e.g. 3×3 or 2×2) of weights. Different kernels detect different things — a horizontal edge, a vertical edge, a diagonal.
Feature map
The output grid of responses. Bright where the kernel's pattern is present, dark where it isn't.

What If I Have Multiple Filters?

Many kernels → a stack of feature maps

One kernel finds one kind of edge. Use n kernels and you get n feature maps stacked into a volume — each channel answering a different "is this pattern here?"

28×28 image  —(n filters, 5×5)→  24 × 24 × nDepth n = how many different patterns we look for at this layer.
Learnable filters
We don't hand-pick the kernel numbers. They start random and gradient descent + backpropagation tune them so the network extracts the lines, edges and contours that help classification.
This is the key shift: edge detectors become weights the network learns, not fixed formulas.
What If I Stack Layers of Filters?

Shallow layers see edges; deep layers see objects

➖

Layer 1

Simple lines & edges — horizontal, vertical, diagonal strokes.

🔺

Layer 2–3

Corners, curves and contours — combinations of layer-1 edges.

👁️

Deeper

Parts and shapes — an eye, a wheel, the loop of a digit.

🐱

Top

Whole-object patterns — enough to say "cat" vs "dog".

Transfer learning preview: because early layers learn generic edges, a network trained on millions of images can be reused — keep its edge/contour layers, retrain only the top for your task.
From Feature Maps to a Prediction

Convolve → flatten → classify

After the convolutional layers extract features, the final volume (e.g. 4×4×100 = 1600) is flattened and fed to a normal dense head → 128 → … → k class scores (cat / dog / car …).

… conv layers … → flatten (1600) → Dense(128) → … → k classesConvolutions keep spatial info; the dense head makes the final decision. Trained end-to-end with backpropagation.
import torch.nn as nn
model = nn.Sequential(
    nn.Conv2d(1, 32, kernel_size=3),  # 32 learnable filters
    nn.ReLU(),
    nn.Conv2d(32, 64, kernel_size=3),
    nn.ReLU(),
    nn.Flatten(),
    nn.Linear(64*24*24, 128), nn.ReLU(),
    nn.Linear(128, 10)                # k classes
)
