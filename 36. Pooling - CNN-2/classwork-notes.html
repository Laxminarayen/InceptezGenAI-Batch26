Pooling — CNNs, Part 2

Convolution turns an image into feature maps, but we don't need every value at full resolution. Pooling summarises each small region into one number — shrinking the maps while keeping the pattern. That's the operation that finally turns stacked convolutions into a full CNN, which we then train on cats vs dogs and deploy to AWS EC2.

Part I: Representations — Global vs Spatial / Local

Two ways to represent an image for a model:

  • Global representation (simple neural network): flatten the image into one long vector (e.g. 10,000 values → a dimensionality-reduced vector of rows × cols) and take a global, non-linear weighted sum. Fast, but where pixels sit is lost.
  • Spatial / local representation (CNN): a small kernel / filter slides over the image to capture edges, corners, lines and curves. The network learns these kernels.

Kernel sizes are usually small and odd: 2×2, 3×3, 5×5, 7×7, 9×9. A square kernel (m = n) is the norm, though not mandatory. Convolution with 128 filters turns a 28×28×1 image into a 24×24×128 stack of feature maps — the filter number is the depth.

Convolution vocabulary (recap)

  1. Convolution — slide a filter, multiply & sum each patch.
  2. Filters — many kernels → many feature maps.
  3. Weights — the filter values themselves.
  4. Striding — how far the filter jumps each step; stride = 1 moves one pixel at a time.
  5. Feature maps — the outputs. Backprop tunes the filter weights.

Part II: Pooling — Do We Need Every Single Value?

After convolution the CNN produces feature maps = patterns in the image. For a 1920×1080 (1080p) frame these maps are huge. Do we need every single value at its original resolution? NOT ALWAYS!

The question: what is a really efficient way to summarise a small region into a single value? Two common answers:
  • Max pooling — take the max value from a small region (the strongest response).
  • Average pooling — take the average of the values in the small region.
  • (and Min pooling — the smallest value; less common.)

Worked example — a 4×4 map, 2×2 regions (stride 2)

Split the map into non-overlapping 2×2 regions and summarise each:

row 171   06   6

So Max → [[71, 6], [60, 13]], Avg → [[20, 5], [40, 7.5]], Min → [[0, 2], [20, 3]]. The 4×4 map becomes a 2×2 map — a reduced-dimensionality image with the same information retained.

Advantages of pooling

  1. Reduces spatial dimensions of the feature maps.
  2. Reduces computation downstream.
  3. Summarises the local response (and adds a little translation tolerance).

Two interview questions

  1. Does the pooling layer have weights & biases? No — standard Max / Avg pooling has no learnable W's or B's. It is a fixed rule.
  2. Does backpropagation pass through pooling? Yes! No learnable parameters does not mean no backpropagation — gradients still flow back to the conv layers below. (Max pooling routes the gradient to whichever cell was the max.)

Part III: The Full CNN Pipeline

Putting it together, a CNN alternates convolution and pooling, then flattens into a dense head:

28×28 image → [Conv → ReLU → Max Pool] → [Conv → ReLU → Max Pool] → Flatten → Fully-Connected → outputs Conv layers (with weights W, b) learn local patterns; pooling reduces spatial dims; the flattened vector feeds a fully-connected layer for decision making (a simple NN head). Trained end-to-end with backpropagation.

Colour images & 3-D filters: an RGB image has 3 channels (R, G, B), so each filter is actually 3-D — one slice per input channel. Convolution sums across all channels; pooling then shrinks each output map.

Part IV: Practical — Cats vs Dogs, then EC2

We build a real CNN that classifies cats vs dogs from 128×128 colour photos, train it in Colab, save the best weights, wrap it in a small Flask web app, and deploy it to an AWS EC2 instance.

self.network = nn.Sequential(
    nn.Conv2d(3, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),   # 128 → 64
    nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),  # 64 → 32
    nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),  # 32 → 16
    nn.AdaptiveAvgPool2d((4, 4)), nn.Flatten(),                   # 16 → 4 → 1024
    nn.Linear(64*4*4, 32), nn.ReLU(),
    nn.Linear(32, 2))                                             # Cat / Dog
