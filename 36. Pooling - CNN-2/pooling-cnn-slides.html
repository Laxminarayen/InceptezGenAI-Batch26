Recap · Two Ways to Represent an Image

Global vs spatial / local

A simple neural network flattens the image into one long vector and takes a global weighted sum — a dimensionality-reduced vector that has lost where things are. A CNN keeps the spatial / local representation: a small kernel / filter slides over the image to detect edges, corners, lines and curves.

Kernel / Filter
Learns local patterns — edges, corners, lines, curves. Sizes are usually odd: 2×2, 3×3, 5×5, 7×7, 9×9 (m = n is the norm, not mandatory). The network learns these kernels.
28×28×1 —(128 filters)→ 24×24×128Convolution → feature maps. Depth = number of filters. But do we keep every value at full resolution?

Part II · After Convolution

Do we need every single value?

After convolution, the CNN produces feature maps = patterns in the image. A 1920×1080 (1080p) frame makes huge maps. Do we really need each one at its original resolution?

NOT ALWAYS! What's a really efficient way to summarise a small region into a single value?
Pooling
Slide a small window over a feature map and replace each region with one summary number — the max, the average, (or the min). Fewer numbers, same pattern.
Reduced-dimensionality image → same information retained, far fewer values to compute on.
Why Bother? · Advantages

Three reasons pooling pays off

📐

Reduces spatial dimensions

A 24×24 map → 12×12 after 2×2 pooling. Smaller maps flow through the rest of the network.

⚡

Reduces computation

Fewer values = fewer multiply-adds downstream = faster training and inference.

🎯

Summarises local response

Keeps "was the feature here, roughly?" — a little translation-tolerance for free.

✓ Pooling is the cheap down-sampler that sits between convolution blocks.
Pooling, Live · Pick a type, press ▶

Summarise each 2×2 region into one number

A 2×2 window (stride 2, non-overlapping) slides over the 4×4 map.
Input 4×4 · window 2×2 · stride 2 → output 2×2. Max keeps the strongest response; Avg smooths; Min keeps the weakest.

Two Classic Interview Questions

Pooling has no weights — but backprop still flows

❓

Does pooling have weights & biases?

No. Standard Max / Avg pooling has no learnable W's or B's — it's a fixed rule, nothing to train.

🔁

Does backprop pass through pooling?

Yes! No learnable parameters does not mean no backpropagation. Gradients still flow back to the conv layers below (max-pool routes the gradient to the max cell).

✓ So pooling trains nothing itself, yet it sits happily inside the end-to-end trained network.
Part III · The Full CNN Pipeline

Conv → ReLU → Pool → … → Flatten → FC

28×28 image → [Conv → ReLU → MaxPool] → [Conv → ReLU → MaxPool] → Flatten → Fully-Connected → outputs
🔲

Conv + ReLU

Learn local patterns with filters (W, b), add non-linearity.

🗜️

Max Pool

Reduce spatial dims; summarise the response. Repeat the block.

➡️

Flatten → FC

Turn the final volume into a vector → dense layer for decision making (a simple NN head).

🔁

Backprop

One end-to-end training loop tunes every conv filter and FC weight.

Practical · Cats vs Dogs

A real CNN, in PyTorch

Three Conv→ReLU→MaxPool blocks (3→16→32→64 channels), an AdaptiveAvgPool2d((4,4)) to a fixed size, then flatten → 32 → 2 classes. Trained with Adam + CrossEntropyLoss on 128×128 colour images.

self.network = nn.Sequential(
    nn.Conv2d(3, 16, 3, padding=1), nn.ReLU(),
    nn.MaxPool2d(2),                      # 128 → 64
    nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(),
    nn.MaxPool2d(2),                      # 64 → 32
    nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(),
    nn.MaxPool2d(2),                      # 32 → 16
    nn.AdaptiveAvgPool2d((4, 4)),         # 16 → 4
    nn.Flatten(),
    nn.Linear(64*4*4, 32), nn.ReLU(),
    nn.Linear(32, 2))                     # Cat / Dog

Recap

Pooling = cheap, smart down-sampling

Convolution finds patterns; pooling summarises a region into one value (Max / Avg / Min), shrinking the maps while keeping the signal. It has no weights, yet backprop flows through it. Stack Conv→ReLU→Pool blocks, flatten into a dense head, and you have a full CNN — now classifying cats vs dogs and deployed to EC2.
