1.Recap: Global vs Spatial Representation

A simple neural network flattens the image and takes a global weighted sum — a dimensionality-reduced vector that has lost where pixels are. A CNN keeps the spatial / local representation: a learnable kernel / filter slides over the image to detect edges, corners, lines and curves. Kernel sizes are small and usually odd — 2×2, 3×3, 5×5, 7×7, 9×9 (square is the norm, not mandatory). Convolution with 128 filters turns 28×28×1 into a 24×24×128 feature-map stack.

2.The Problem: Do We Need Full Resolution?

After convolution the CNN holds feature maps that encode patterns in the image. For large inputs (e.g. 1920×1080) these maps are enormous. Do we need every single value at its original resolution? Not always. We want a cheap way to summarise a small region into a single value — that operation is pooling.

3.The Pooling Operation

Slide a small window (commonly 2×2) over the feature map and replace each region with one summary number. With stride = window size the regions don't overlap, so an N×N map becomes (N/2)×(N/2).

  • Max pooling — the maximum value in the region (keeps the strongest "feature fired here" signal). The CNN default.
  • Average pooling — the mean of the region (smooths the response).
  • Min pooling — the minimum value (rarely used).

4.Worked Example (4×4 → 2×2)

Split the map into four non-overlapping 2×2 regions and summarise each three ways:

Region (2×2 values)MaxAverageMin
{8, 1, 71, 0}71(8+1+71+0)/4 = 200
{6, 2, 6, 6}620/4 = 52
{50, 30, 20, 60}60160/4 = 4020

6.No Weights, Yet Backprop Flows

Two classic interview questions:

QuestionAnswer
Does the pooling layer have weights & biases?No. Standard Max / Avg pooling has no learnable W's or B's — it applies a fixed rule.
Does backpropagation pass through pooling?Yes. No learnable parameters does not mean no backprop. Gradients still flow back to the conv layers below.
How the gradient routes: for max pooling, the gradient of the output goes entirely to the cell that was the maximum (the others get 0). For average pooling, the gradient is split equally across all cells in the region. Either way the signal reaches the trainable filters beneath.

7.Advantages & Output Size

  1. Reduces spatial dimensions — a 24×24 map → 12×12 after 2×2 pooling.
  2. Reduces computation downstream (fewer multiply-adds).
  3. Summarises the local response and adds mild translation tolerance.
output side = ⌊(input − window) / stride⌋ + 1For the common case window = stride = 2: output = input / 2. So 128 → 64 → 32 → 16 through three pooling layers.

9.Colour Images & 3-D Filters

A colour image has three channels — R, G, B. So each convolution filter is actually 3-D: one 2-D slice per input channel. The filter multiplies and sums across all channels at once to produce a single feature-map value, and pooling then shrinks each resulting map. (A layer with 16 such 3-D filters on an RGB input produces 16 feature maps.)

10.Summary

The whole idea, in one paragraph

Convolution finds patterns and produces feature maps, but keeping them at full resolution is wasteful. Pooling summarises each small region into one value — Max (strongest, the default), Average (smoothed) or Min — so an N×N map becomes (N/2)×(N/2) with a 2×2 window. It reduces spatial dimensions and computation while keeping the signal, has no learnable weights, yet backpropagation still flows through it (max-pool routes the gradient to the max cell). Stack Conv→ReLU→MaxPool blocks, flatten, and attach a fully-connected head and you have a complete CNN — the architecture behind our cats-vs-dogs classifier, deployed to AWS EC2.
