Cell 4.Load Data, Split, Corrupt Labels

the rigged experiment 
digits = load_digits()
images_np = digits.images.astype("float32") / 16.0   # pixels 0..16 → 0..1
labels_clean = digits.target.astype("int64")
images = torch.tensor(images_np[:, None, :, :])     # shape (N, 1, 8, 8)

all_ids = np.arange(len(labels_clean))
train_val_ids, test_ids = train_test_split(
    all_ids, test_size=0.20, stratify=labels_clean, random_state=SEED)
train_pool_ids, val_ids = train_test_split(
    train_val_ids, test_size=0.25, stratify=labels_clean[train_val_ids], random_state=SEED)

rng = np.random.default_rng(SEED)
train_pool_ids = rng.permutation(train_pool_ids)
small_train_ids = train_pool_ids[:120]
large_train_ids = train_pool_ids[:800]

labels_noisy = labels_clean.copy()
corrupted_ids = rng.choice(train_pool_ids, size=len(train_pool_ids)//4, replace=False)
labels_noisy[corrupted_ids] = (labels_clean[corrupted_ids] + rng.integers(1, 10, ...)) % 10
  • / 16.0 — sklearn digits are 0–16; dividing scales to 0–1 for stable training.
  • images_np[:, None, :, :] — insert a channel axis → (N, 1, 8, 8), the (batch, channels, H, W) format PyTorch convolutions expect.
  • Two stratified splits — first peel off 20% for test; then split the rest into train pool and validation (stratify= keeps class proportions in every split).
  • small_train_ids / large_train_ids — the same shuffled pool sliced to 120 (tiny, overfit-prone) and 800 (the "more data" run).
  • Label corruption — copy the clean labels, pick 25% of the training pool, and replace each with a different digit: (true + random 1..9) % 10 guarantees the new label is wrong (never equal to the original). Validation/test labels are never touched.
  • The cell's asserts confirm train/val/test don't overlap — a leakage check.

Cell 8.The MLP & CNN Models

two architectures, dropout optional 
class MLP(nn.Module):
  def __init__(self, small=False, dropout=False, num_classes=10):
    h1, h2 = (32, 16) if small else (256, 128)
    self.network = nn.Sequential(
        nn.Flatten(),
        nn.Linear(64, h1), nn.ReLU(),
        nn.Dropout(0.4) if dropout else nn.Identity(),   # toggle dropout
        nn.Linear(h1, h2), nn.ReLU(),
        nn.Dropout(0.4) if dropout else nn.Identity(),
        nn.Linear(h2, num_classes))
class SimpleCNN(nn.Module):
  def __init__(self, small=False, dropout=False, num_classes=10):
    c1, c2 = (8, 16) if small else (32, 64)
    self.features = nn.Sequential(
        nn.Conv2d(1, c1, 3, padding=1), nn.ReLU(),
        nn.Conv2d(c1, c2, 3, padding=1), nn.ReLU(),
        nn.Dropout2d(0.2) if dropout else nn.Identity(),   # spatial dropout
        nn.MaxPool2d(2),
        nn.Conv2d(c2, c2, 3, padding=1), nn.ReLU(),
        nn.Dropout2d(0.2) if dropout else nn.Identity(),
        nn.MaxPool2d(2), nn.Flatten(),
        nn.Linear(c2*2*2, hidden), nn.ReLU(),
        nn.Dropout(0.4) if dropout else nn.Identity())
    self.classifier = nn.Linear(hidden, num_classes)
  • The if dropout else nn.Identity() trick — nn.Identity() is a pass-through layer, so the same model definition works with and without dropout. One flag flips regularization on/off.
  • small flag — swaps the hidden sizes (256/128 → 32/16 for the MLP; 32/64 → 8/16 channels for the CNN), giving a low-capacity variant for the "smaller model" fix.
  • num_classes — 10 for digits; set to 2 later for the Even-vs-Odd transfer task.
  • CNN structure — two conv+ReLU blocks, spatial dropout, pooling (8×8 → 4×4 → 2×2), then a dense head. c2*2*2 is the flattened size after the two MaxPool2d(2) halvings.
  • count_params() — sums p.numel() over trainable parameters (numel = number of elements in a tensor). Prints how much bigger the full model is than the "small" one.

Cell 10a.augment_batch()

train-only augmentation 
def augment_batch(x):
    n = x.shape[0]
    angle = (torch.rand(n) - 0.5) * 0.30   # ± ~8.6° rotation
    tx = (torch.rand(n) - 0.5) * 0.14      # small horizontal shift
    ty = (torch.rand(n) - 0.5) * 0.14      # small vertical shift
    theta = torch.zeros(n, 2, 3)             # 2×3 affine matrix per image
    theta[:,0,0]=torch.cos(angle); theta[:,0,1]=-torch.sin(angle)
    theta[:,1,0]=torch.sin(angle); theta[:,1,1]= torch.cos(angle)
    theta[:,0,2]=tx; theta[:,1,2]=ty
    grid = F.affine_grid(theta, x.shape, align_corners=False)
    return F.grid_sample(x, grid, align_corners=False, padding_mode="zeros")
  • Builds a small random rotation + translation per image as a 2×3 affine matrix theta (the top-left 2×2 is a rotation; the last column is the shift).
  • affine_grid + grid_sample — the standard PyTorch way to apply a geometric transform differentiably: build a sampling grid from theta, then resample the image through it.
  • These are label-preserving (a slightly rotated 3 is still a 3) and applied only in training — never to validation/test.

Cell 10b.evaluate()

fair measurement 
def evaluate(model, ids, labels):
    model.eval()                              # turn OFF dropout
    with torch.inference_mode():
        y = torch.tensor(labels[ids], dtype=torch.long)
        logits = model(images[ids])
        loss = F.cross_entropy(logits, y).item()
        accuracy = (logits.argmax(1) == y).float().mean().item()
    return loss, accuracy
  • model.eval() — critical: disables dropout (and freezes any BatchNorm stats) so the measurement is deterministic and fair. Pair it with model.train() inside the loop.
  • torch.inference_mode() — no gradient tracking → faster, less memory during scoring.
  • Returns both loss (for model selection) and accuracy (for reporting).

Cell 10c.fit() — the Shared Training Loop

one function drives every experiment 
def fit(model, train_ids, train_labels, val_labels=labels_clean,
        epochs=100, lr=0.003, weight_decay=0.0, augment=False, patience=None):
    torch.manual_seed(123)                   # same init for a fair comparison
    ds = TensorDataset(images[train_ids], torch.tensor(train_labels[train_ids]))
    loader = DataLoader(ds, batch_size=32, shuffle=True)
    optimizer = torch.optim.AdamW(
        (p for p in model.parameters() if p.requires_grad),
        lr=lr, weight_decay=weight_decay)       # weight_decay = L2
    best_loss, best_state, stale_epochs = float("inf"), None, 0

    for epoch in range(1, epochs+1):
        model.train()                           # turn ON dropout
        for x, y in loader:
            if augment: x = augment_batch(x)       # train-only
            optimizer.zero_grad()
            loss = F.cross_entropy(model(x), y)
            loss.backward()
            optimizer.step()
        train_loss, train_acc = evaluate(model, train_ids, train_labels)
        val_loss,   val_acc   = evaluate(model, val_ids, val_labels)
        history.append(dict(epoch=epoch, train_loss=train_loss, val_loss=val_loss, ...))
        if val_loss < best_loss - 0.001:          # improved?
            best_loss, best_state, stale_epochs = val_loss, copy.deepcopy(model.state_dict()), 0
        else:
            stale_epochs += 1
        if patience is not None and stale_epochs >= patience:
            break                               # EARLY STOPPING
    if patience is not None and best_state:
        model.load_state_dict(best_state)       # restore BEST checkpoint

This one function implements several fixes through its arguments:

ArgumentFix it enables
weight_decay=0.1L2 regularization (passed straight to AdamW)
augment=TrueData augmentation in the batch loop
patience=10Early stopping + best-checkpoint restore
model built with dropout=/small=Dropout / smaller model
train_ids, train_labelsMore data / clean labels
  • torch.manual_seed(123) at the top — re-seeds so every experiment starts from the same weight init and shuffling, making the comparisons fair.
  • The 4-step batch — zero_grad → forward+loss → backward → step. AdamW applies the weight_decay (L2) as it updates.
  • Best-checkpoint tracking — whenever validation loss improves by more than 0.001, snapshot the weights with deepcopy and reset the stale counter; otherwise count a stale epoch.
  • Early stopping — only active when patience is set: break after patience stale epochs, then restore the best checkpoint (not the last one). Other experiments keep their final weights.
Honest-comparison caveat (from the notebook): early-stopping runs are restored to their best checkpoint, while other rows report their final epoch — done deliberately for teaching, not as a rigorous matched-compute benchmark. The "more data" run also does more optimization steps per epoch.

Cell 17.Dropout2d, Visualized

what spatial dropout does 
torch.manual_seed(7)
drop = nn.Dropout2d(p=0.5)
drop.train()                               # dropout only acts in train mode
example_maps = torch.ones(1, 8, 4, 4)      # 8 feature maps of 4×4 ones
masked = drop(example_maps)
print(masked.mean(dim=(2,3)).numpy().round(1))  # per-channel mean
  • Feeds 8 all-ones channels through Dropout2d(0.5). Printing each channel's mean shows some channels become entirely 0.0 (dropped) and others are scaled up — confirming it zeroes whole channels, not scattered pixels.
  • drop.train() — dropout is a no-op in eval mode, so the demo explicitly switches to train mode to see the effect.
  • It does not change filter weights — only masks activations during training.

Cells 19–22.One Fix at a Time

the experiment grid 
mlp_cases = [
    ("MLP / Dropout",       dict(dropout=True)),
    ("MLP / Weight decay",  dict(weight_decay=0.1)),
    ("MLP / Early stopping",dict(patience=10)),
    ("MLP / Smaller model", dict(small=True)),
    ("MLP / Augmentation",  dict(augment=True)),
    ("MLP / More data",     dict(more_data=True, epochs=20)),
    ("MLP / Correct labels",dict(clean_labels=True)),
]
for title, cfg in mlp_cases:
    model = MLP(small=cfg.pop("small", False), dropout=cfg.pop("dropout", False))
    train_ids = large_train_ids if cfg.pop("more_data", False) else small_train_ids
    train_targets = labels_clean if cfg.pop("clean_labels", False) else labels_noisy
    experiments[title] = fit(model, train_ids, train_targets, **cfg)
  • Each case is a name + a small config dict. The loop pops the model-construction and data-selection keys out of the dict and passes whatever remains straight to fit() as keyword arguments — a clean way to run many variants with one code path.
  • Change one thing at a time so each effect is attributable. The CNN grid is the same plus a "Combined fixes" row (dropout + weight decay + augment + early stopping).
  • The summary table (cell 22) collects every run's epochs, parameter count, train/val accuracy and val loss. For early-stopping / combined runs it re-evaluates the restored best model; others report the final epoch — and the comparison is interpreted via validation loss, not training accuracy.

Cells 26–30.Transfer Learning & the Honest Final Test

reuse features, then test once 
# pretrain on all 10 digits, then reuse the frozen features for Even-vs-Odd
pretrained = fit(SimpleCNN(num_classes=10), source_ids, labels_clean, epochs=25)
transfer_model = SimpleCNN(num_classes=2)
transfer_model.features.load_state_dict(pretrained["model"].features.state_dict())
for p in transfer_model.features.parameters():
    p.requires_grad = False               # freeze backbone
scratch_model = SimpleCNN(num_classes=2)   # baseline: learn from scratch
  • Disjoint IDs — source_ids (800 for pretraining) and target_ids (80 for the new task) don't overlap, checked with an assert.
  • Reuse + freeze — copy the pretrained features into a fresh 2-class model and freeze them, so only the new head trains on the 80 Even-vs-Odd examples. Compared head-to-head against a model trained from scratch on the same 80.
  • The final test (cell 30) — pick the CNN experiment with the lowest validation loss, then evaluate it once on the untouched test set and draw a confusion matrix. The rule the whole lab enforces: validation chooses, test confirms — never tune on test.

In one paragraph

The lab loads sklearn's 8×8 digits, makes stratified train/val/test splits, and deliberately corrupts 25% of a tiny training set's labels to force overfitting. It defines an MLP and a CNN (dropout and size togg=able) and one shared fit() whose arguments switch on each fix — weight decay, augmentation, early stopping with best-checkpoint restore, dropout, smaller model, more/cleaner data. Baselines show training accuracy hitting ~100% while validation loss rises; each fix is run one-at-a-time and compared by validation loss. It finishes with a transfer-learning comparison (frozen pretrained features vs scratch on 80 examples) and one honest test: select on validation, evaluate once on the held-out set. The lesson: a low training loss never guarantees real-world performance.
