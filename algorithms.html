Traditional Machine Learning

Supervised & Unsupervised

Models that learn predictive relationships from human-engineered features.

Supervised Learning Regression

Predict a continuous number (price, salary, temperature).

Linear Regression Fit a straight line / plane. The foundation of regression and of the neuron itself.
Taught · Class 17–20
Polynomial Regression Adds powers of the input to bend the line — still a linear model in its parameters.
Taught · Class 21
KNN Regression Predict from the average of the k nearest neighbours by distance.
Taught · Class 24
Decision Tree Regression Split the feature space into regions; predict each region's mean.
Taught · Class 24–25
Random Forest Regression An ensemble of decision trees (bagging), averaged for a stable prediction.
Taught · Class 28

Supervised Learning Classification

Predict a category / label (spam vs not, approve vs reject).

Logistic Regression Linear model + sigmoid → class probability. The classification workhorse.
Taught · Class 22
K-Nearest Neighbors (KNN) Vote of the k closest points, by Euclidean / Manhattan / Mahalanobis / Cosine distance.
Taught · Class 23
Decision Tree Recursive if/else splits on features chosen by information gain / Gini.
Taught · Class 24–25
Random Forest (Bagging) Many independent trees on bootstrapped data, aggregated by majority vote.
Taught · Class 28
AdaBoost (Boosting) Sequential weak stumps, each fixing the last one's mistakes via reweighting.
Taught · Class 29
Gradient Boosting (GBM) Boosting generalised to any differentiable loss by fitting residuals. Not in our syllabus.
Good to know
XGBoost The industrial-strength gradient boosting library — a frequent Kaggle winner on tabular data.
Good to know
Support Vector Machine (SVM) Maximum-margin classifier; kernels add non-linearity. Advanced ML — good to know.
Good to know
Naive Bayes Probabilistic classifier assuming feature independence. Rarely the right tool today.
Not required

Unsupervised Learning Clustering

Find structure with no labels — group similar points together.

K-Means Clustering Partition points into K groups by nearest centroid; the default clustering algorithm.
Taught · Class 30
Hierarchical Clustering Builds a tree of clusters (Agglomerative / DIANA) — useful when K is unknown or features are categorical.
Good to know
DBSCAN Density-based clustering that finds arbitrary shapes and labels outliers as noise.
Good to know

Deep Learning

Neural Networks

Models that learn their own features through trained layers of neurons.

Multi-Layer Perceptron (MLP) A feedforward neural network — input → hidden layers of neurons (affine + activation) → output. The architecture we're currently learning, and the foundation of all deep learning.
Currently teaching · Class 31
Where this is heading: the MLP is the base unit. Specialised architectures build on it — CNNs for images, RNNs / LSTMs for sequences, and Transformers for language, which are what power modern GenAI and ChatGPT. Our agenda has always been Traditional ML → Deep Learning → GenAI; this section grows as we cover each one.
